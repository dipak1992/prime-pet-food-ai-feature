## Technical Specifications

- **Format**: RAW + high-res JPEG (minimum 3000px on longest edge)
- **Aspect ratios needed**: 16:9 (hero banners), 1:1 (cards/social), 4:3 (section images)
- **Color palette**: Warm neutrals, cream tones, natural wood — match brand palette (#fffaf2, #b85f32, #171512)
- **Lighting**: Natural light preferred. Warm, golden tones. No harsh flash.
- **Style**: Editorial lifestyle — not stock photography. Should feel like a real home, real dog, real moment.
- **Dogs**: Must appear calm, focused, and genuinely engaged with the chew. No staged "looking at camera" shots.

## File Naming Convention

```
prime-lifestyle-[category]-[description].jpg
```

Examples:
- `prime-lifestyle-home-golden-sofa-chew.jpg`
- `prime-lifestyle-nepal-yak-hillside.jpg`
- `prime-lifestyle-puff-before-after.jpg`

## Shopify Asset Integration

Upload all final images to `assets/` with the naming convention above. Reference in Liquid as:
```liquid
{{ 'prime-lifestyle-home-golden-sofa-chew.jpg' | asset_url }}
```

Or upload to Shopify Files (Settings > Files) for CDN delivery:
```liquid
shopify://files/images/prime-lifestyle-home-golden-sofa-chew.jpg
```
